# StarBreaker: Unlimited Drill（H5 版）

太空放置採礦 × 彈幕射擊 × 技能融合。**零建置純前端**：`index.html` ＋ `css/` ＋ `js/`，沒有 npm、沒有打包，任何靜態伺服器或 `file://` 都能跑。

## 線上版（已發佈）

**https://bodhi16889.github.io/starbreaker-h5/**

手機直接開，加到主畫面就像 App。`?lang=en` 切英文。

## 怎麼跑（本機

```bash
cd ~/work/starbreaker-h5
/usr/bin/python3 -m http.server 8080
# 電腦： http://127.0.0.1:8080/
# 手機（同一個 Wi-Fi）： http://<這台電腦的 IP>:8080/
```

不想開伺服器也可以直接雙擊 `index.html`（`file://` 一樣能玩，只是存檔綁在該瀏覽器）。

參數：`?lang=en` 切英文介面（預設繁體中文）。

## 還沒做（誠實清單）

- **沒有美術素材**：方塊、飛船、衛星都是程式繪製的幾何圖形，不是 sprite。
- **迫擊炮／殲星主砲是即時判定**，沒有真正的拋物線飛行與光束逐格推進（視覺有爆炸環與光束條）。
- **沒有音效／音樂**。
- **沒有原生打包**（這是 H5；要上 App Store／Google Play 需要另外包 Capacitor 或重寫原生）。
- **沒有多語系完整翻譯**：`?lang=en` 只切 UI 標題，武器／技能名稱仍是中文。
- **沒有雲端存檔**：只有 localStorage（主檔 ＋ `.bak` 備援，壞檔會回退）。

## Step 3 移植時修掉的設計問題

原 GDScript 的雷射衛星是「飛船 ↔ 衛星」連線切割，但兩者都在星球外側，
線段永遠不會碰到方塊（H5 實測切割次數 0）。改成「衛星 ↔ 目標」延伸光束（穿過目標再往前 60px），
飛船↔衛星那條只留細線當視覺連結。

## 已知的觸控細節

`#game` 必須 `touch-action: none`，否則手機會把拖曳當成頁面捲動、中途發 `pointercancel`，
搖桿會消失、飛船彈回軌道（實測 CDP touch 事件才抓得到，滑鼠完全正常）。

## 專案結構

```
index.html          UI 骨架（HUD / canvas / 五個分頁 / 彈窗）
css/style.css       9:16 直式、安全區、44px 觸控目標
js/big.js           大數格式化（K/M/B/T/aa…）
js/config.js        全部平衡參數（武器／衛星／技能／通行證／禮包）
js/state.js         存檔、資源、升級、技能融合、轉生、通行證
js/planet.js        星球生成、方塊傷害、連鎖爆炸（純資料）
js/game.js          主循環、飛船、武器、衛星、物件池、canvas 渲染
js/ui.js            HUD 與彈窗（唯一碰 DOM 的檔案）
tests/smoke.py      Playwright 22 項（含 640×480、存檔、搖桿、清空推進）
tests/test_sats.py  Playwright 16 項（Step 3 衛星：軌道半徑、六顆不重疊、五種能力計數、傷害公式）
```
